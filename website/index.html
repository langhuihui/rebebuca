Features

🚀

Quick Launch

Create and run configurations with one click, no need to memorize complex commands

⚡

Real-time Output

View command execution results in real-time with multi-tab support

Configuration Management

Support for advanced options like working directory and environment variables

🕒

History Tracking

Automatically save run history for easy re-execution

Modern UI
