## 技术架构

### 技术栈

- **前端框架**: Vue 3 (Composition API)
- **UI 组件库**: Naive UI
- **状态管理**: Pinia
- **类型系统**: TypeScript
- **命令执行**: Tauri 2 + PTY
- **数据存储**: Tauri Store / LocalStorage

### 架构层次

```
┌─────────────────────────────────────┐
│      Presentation Layer            │
│  (Vue Components: 24 components)  │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│      State Management            │
│  (Pinia Stores: 2 stores)      │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│        Service Layer             │
│  (Services: 5 services)        │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│         Data Layer               │
│  (Static Data, Utils, Types)    │
└─────────────────────────────────────┘
```

### 目录结构

```
src/ffmpeg/
```
