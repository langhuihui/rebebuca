## 已知问题和限制

1. **插帧滤镜性能**: 插帧非常耗时，仅推荐在必要时使用
2. **滤镜预览**: 当前不支持实时滤镜预览（预留接口）
3. **GPU 检测**: GPU 信息检测是模拟的，需要实际调用系统 API
4. **字幕样式**: 复杂的 ASS 样式可能需要额外处理
5. **滤镜顺序**: 滤镜链排序后需要重新生成命令，当前是简化实现
