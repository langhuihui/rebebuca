## 一、快速入门

### 1.1 安装 FFmpeg

在使用 Rebebuca 的 FFmpeg 功能之前,需要先安装 FFmpeg。

#### Windows

1. 下载 FFmpeg: https://www.gyan.dev/ffmpeg/builds/
2. 解压到任意目录,例如 `C:\ffmpeg`
3. 添加到系统 PATH:
   - 右键"此电脑" -> 属性 -> 高级系统设置 -> 环境变量
   - 在"系统变量"中找到 `Path`,点击"编辑"
   - 添加 `C:\ffmpeg\bin`
4. 验证安装: 打开命令提示符,输入 `ffmpeg -version`

#### macOS

```bash
# 使用 Homebrew 安装
brew install ffmpeg
```

#### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install ffmpeg
```

### 1.2 启动应用

1. 双击 Rebebuca 应用图标
2. 在左侧导航栏中找到"视频编码"模块
3. 点击进入 FFmpeg 视频编码页面

### 1.3 首次使用

1. **选择模式**: 默认为简单模式,适合新手使用
2. **添加文件**: 拖拽视频文件到界面,或点击"添加文件"按钮
3. **配置参数**:
   - 简单模式:选择快速场景或调整常用参数
   - 专家模式:配置所有详细参数
4. **预览命令**: 查看生成的 FFmpeg 命令
5. **开始转码**: 点击"开始转码"按钮
6. **监控进度**: 查看实时进度和状态信息

## 二、简单模式

简单模式只显示最常用的参数,适合新手用户。

### 2.1 快速场景

提供4个快速场景,一键应用推荐配置:

- **保持原画质**: CRF 20, 原分辨率, 高质量音频
- **快速压缩**: CRF 28, 720p, 标准音频
- **格式转换**: CRF 23, 原分辨率, 标准音频
- **高质量**: CRF 18, 1080p, 高质量音频

### 2.2 输出格式

选择输出视频容器格式:

- **MP4 (推荐)**: 通用格式,兼容性好
- **MKV**: 支持更多编码器和功能
- **WebM**: 开源格式,适合网络传输

### 2.3 视频质量

使用 CRF (Constant Rate Factor) 控制视频质量:

- **高质量**: CRF 18-20
- **平衡**: CRF 23 (推荐)
- **小文件**: CRF 26-28

### 2.4 输出分辨率

选择输出视频分辨率:

- **保持原分辨率**: 不改变分辨率
- **4K**: 3840x2160
- **1080p**: 1920x1080 (最常用)
- **720p**: 1280x720
- **480p**: 854x480

### 2.5 音频质量

选择音频比特率:

- **320k**: 高质量
- **192k**: 推荐
- **128k**: 标准
- **96k**: 省空间
- **64k**: 低质量

## 三、专家模式

专家模式显示所有参数配置,适合高级用户。

### 3.1 视频参数

#### 编码器

- **H.264 (libx264)**: 最常用的编码器,兼容性好
- **H.265 (libx265)**: 压缩效率更高,适合 4K
- **VP9**: Google 开发,适合 Web
- **AV1**: 新一代编码器,压缩效率最高

#### 编码预设

控制编码速度和压缩效率:

- **ultrafast**: 最快,文件最大
- **fast**: 较快,文件较大
- **medium**: 平衡 (推荐)
- **slow**: 较慢,文件较小
- **veryslow**: 最慢,文件最小

#### 质量控制

- **CRF**: 恒定质量模式 (推荐)
- **VBR**: 动态码率
- **CBR**: 恒定码率
- **CQP**: 恒定量化参数

### 3.2 音频参数

#### 编码器

- **AAC**: 最常用的音频编码器
- **MP3 (libmp3lame)**: 通用音频格式
- **Opus**: 高质量,低延迟
- **FLAC**: 无损音频

#### 比特率

音频比特率,越高音质越好:

- **64k-96k**: 标准
- **128k-192k**: 推荐
- **256k-320k**: 高质量

#### 声道数

- **1**: 单声道
- **2**: 立体声 (推荐)
- **6**: 5.1 环绕声

#### 采样率

- **44100 Hz**: CD 质量
- **48000 Hz**: 视频/电影标准
- **96000 Hz**: 高质量

### 3.3 滤镜配置

#### 基础滤镜

- **裁剪**: 裁剪视频画面
- **缩放**: 调整视频尺寸
- **帧率**: 调整视频帧率
- **旋转/翻转**: 旋转或翻转视频

#### 高级滤镜

- **去隔行**: 处理隔行扫描视频
- **降噪**: 降低视频噪点
- **锐化**: 增强画面锐度
- **插帧**: 提升帧率 (非常耗时)

#### 字幕

- **内置字幕**: 烧录内置字幕
- **外部字幕**: 烧录外部字幕文件 (SRT/ASS)
- **字幕样式**: 自定义字幕样式

#### 色彩管理

- **像素格式**: yuv420p (8-bit), yuv420p10le (10-bit)
- **色彩空间**: bt709 (SDR), bt2020 (HDR)
- **传输特性**: bt709, smpte2084 (HDR10), arib-std-b67 (HLG)
- **原色**: bt709, bt2020, DCI-P3

### 3.4 剪辑区间

设置视频的开始和结束时间:

- **开始时间**: HH:MM:SS.mmm
- **结束时间**: HH:MM:SS.mmm
- **时长**: 自动计算

快速设置:
- 首分钟
- 前30秒
- 前10秒
- 前5秒

### 3.5 二遍编码

二遍编码可以提升视频质量,但耗时增加。

**何时使用:**
- 需要精确控制文件大小
- 对质量要求较高
- 不介意耗时

**何时不使用:**
- 快速处理
- CRF 模式 (不推荐)
- 实时编码

### 3.6 硬件加速

使用 GPU 加速编码,大幅提升速度。

#### NVIDIA NVENC

- 支持的编码器: h264_nvenc, hevc_nvenc
- 适合: NVIDIA 显卡用户
- 性能: 优秀

#### Intel QSV

- 支持的编码器: h264_qsv, hevc_qsv
- 适合: Intel 显卡用户
- 性能: 良好

#### AMD AMF

- 支持的编码器: h264_amf, hevc_amf
- 适合: AMD 显卡用户
- 性能: 良好

#### Apple VideoToolbox

- 支持的编码器: h264_videotoolbox, hevc_videotoolbox
- 适合: Mac 用户
- 性能: 优秀

### 3.7 高级选项

#### 解码器配置

- **解码器**: 选择视频解码器
- **硬件加速**: 选择硬件加速方式
- **设备**: 指定硬件设备

#### 流控制

控制要保留的流:

- **保留其他视频流**
- **保留其他音频流**
- **保留字幕流**
- **保留附件流**

#### 元数据

设置输出文件的元数据:

- 标题
- 艺术家
- 专辑
- 年份
- 注释

#### 自定义参数

直接输入自定义 FFmpeg 参数:

- **输入前参数**: `-ss 00:00:10`
- **自定义视频滤镜**: `crop=1920:1080:0:0`
- **自定义音频滤镜**: `volume=0.5`
- **自定义视频参数**: `-x264-params crf=23:me=hex`
- **自定义音频参数**: `-ar 44100 -ac 2`
- **输出后参数**: `-movflags +faststart`

## 四、批量处理

### 4.1 添加任务

1. 添加多个视频文件
2. 自动批量模式切换
3. 点击"批量队列"开关

### 4.2 并发控制

设置同时处理的任务数量 (1-5):

- **1**: 串行处理,最稳定
- **2-3**: 推荐设置
- **4-5**: 适合性能强的机器

### 4.3 任务管理

- **开始**: 开始批量处理
- **暂停**: 暂停所有任务
- **停止**: 停止所有任务
- **清空已完成**: 清理已完成的任务

## 五、预设管理

### 5.1 内置预设

提供常用预设模板:

- **1080p MP4 (H.264)**
- **720p Mobile (H.264)**
- **4K H.265 High Quality**
- **Web 优化 (VP9)**
- **快速压缩 (H.264, ultrafast)**

### 5.2 自定义预设

1. 配置参数
2. 点击"保存预设"
3. 输入预设名称
4. 保存成功

### 5.3 导入/导出

#### 导入 3FUI 预设

1. 点击"导入预设"
2. 选择 `.3fui` 文件
3. 自动映射参数
4. 添加到预设列表

#### 导出预设

1. 选择要导出的预设
2. 点击"导出预设"
3. 选择导出格式 (Rebebuca JSON / 3FUI)
4. 保存文件

## 六、常见问题

### 6.1 FFmpeg 相关

#### Q: FFmpeg 未安装怎么办?

A: 请参考 [1.1 安装 FFmpeg](#11-安装-ffmpeg) 部分的说明。

#### Q: 如何检查 FFmpeg 版本?

A: 打开命令行,输入:
```bash
ffmpeg -version
```

#### Q: FFmpeg 版本过旧怎么办?

A: 下载最新版本的 FFmpeg 并安装。

### 6.2 性能优化

#### Q: 如何提升转码速度?

A:
1. 使用硬件加速 (NVENC/QSV/AMF)
2. 使用更快的编码预设 (ultrafast/fast)
3. 降低分辨率
4. 提高并发数

#### Q: 如何减小文件大小?

A:
1. 提高 CRF 值
2. 降低分辨率
3. 使用 H.265 编码器
4. 降低音频比特率

#### Q: 如何提升视频质量?

A:
1. 降低 CRF 值
2. 使用更慢的编码预设 (slow/veryslow)
3. 使用二遍编码
4. 提高音频比特率

### 6.3 错误处理

#### Q: 磁盘空间不足怎么办?

A: 清理磁盘空间或选择其他输出目录。

#### Q: 编码器不支持怎么办?

A: 升级 FFmpeg 到最新版本或选择其他编码器。

#### Q: 硬件加速不可用怎么办?

A:
1. 检查驱动是否安装
2. 切换到软件编码器
3. 检查硬件是否支持
